# Conocimiento acerca de DevOps

Lo que se acerca de DevOps es muy poco, basico.
DevOps es una combinación de dos palabras, separando estas palabras da lo siguiente:
Dev = Desarrollo, que es la parte de los programadores     
Ops = Operaciones, esto es el apartado de las redes, al llegar a una empresa la base de datos ya esta creada y puesta en funcionalidad.
DevOps es una forma de trabajar en equipo donde los desarrolladores y el personal de las operaciones colaboran desde un inicio hasta el final del proyecto para poder crear un software más rápido, hacer el software con menos errores, y poder lanzar el software y actualizarlo más seguido.
DevOps lo que busca es automatizar las tareas (pueden ser pruebas o despliegues), evitar los errores humanos, mejorar la comunicación entre áreas y entregar valor al usuario final lo más pronto posible.
DevOps es una cultura y un conjunto de prácticas para que desarrollo y operaciones trabajen juntos, automatizando y mejorando todo el proceso de creación y entrega del software.
